# Expiry

A list of lots sorted by expiry date. Lots that expire soon or have already expired are highlighted.

- **−1** button to consume one unit of a lot (stock goes down and the change is recorded).
- **Editar** (edit) button to change the lot.
- The lot that expires first is the one proposed when consuming.

Related: [Stock](01-stock.md), [Adding lots and scanner](06-adding-lots-and-scanner.md).
