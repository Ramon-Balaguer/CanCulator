# Caducidad

Lista de lotes ordenada por fecha de caducidad. Los que caducan pronto o ya han caducado se destacan.

- Botón **−1** para consumir una unidad del lote (baja el stock y queda registrado).
- Botón **Editar** para cambiar el lote.
- El lote que caduca antes es el que se propone al consumir.

Relacionado: [Stock](01-stock.md), [Alta de lotes](06-alta-de-lotes-y-escaner.md).
