# Imprimir

Tabla imprimible de los lotes. Abre el diálogo de impresión del navegador; «Guardar como PDF» también funciona.

- La lista sale sin la barra de pantallas.
- En iPhone: Compartir → Imprimir, o «Guardar en Archivos» como PDF.
- Muestra la foto de cada producto (la misma función que usa Stock).

Relacionado: [Stock](01-stock.md), [Fotos](08-fotos.md).
