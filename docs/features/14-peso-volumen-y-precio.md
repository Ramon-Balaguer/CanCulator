# Peso, volumen y precio del producto

Campos opcionales en la ficha del producto. Se editan ahí y se usan en Estadísticas.

- **Peso (g)** para los productos sólidos.
- **Volumen (ml)** para aguas y bebidas, y también para tomate, salsas, aceites y condimentos. El formulario muestra el campo que corresponde a la categoría.
- **Precio (€)** por unidad.
- Se rellenan desde el QR GS1 (identificadores 310n, 390n y 392n) o, con código de barras, el precio desde Open Prices.
