# Print (Imprimir)

A printable table of the lots. It opens the browser's print dialog; «Save as PDF» also works.

- The list prints without the screen tab bar.
- On iPhone: Share → Print, or «Guardar en Archivos» (save to Files) as PDF.
- Shows the product photo for each row (the same function Stock uses).
